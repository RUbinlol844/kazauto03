# KAZAUTO 03 — авто маркет в Кокшетау

Одностраничный сайт авто маркета **KAZAUTO 03**: авто в наличии и под заказ,
кредит и рассрочка, trade-in, продажа своего авто. Тема — белый, серебристый
и красный с чёрными акцентами (шапка, полоса преимуществ, блок «Продать авто»).

Чистый HTML/CSS/JS, без сборки и зависимостей. Все фото лежат локально
в папке `img/` — сайт работает даже без интернета.

## Структура

```

```

## Три языка

Сайт работает на русском, казахском и английском. Переключатель **RU / KZ / EN**
стоит в верхней полосе (на телефоне — в меню под навигацией).

- выбор запоминается в браузере посетителя (`localStorage`, ключ `kazauto03_lang`);
- при смене языка переводятся тексты, кнопки, фильтры, карточки авто,
  модальное окно, формы, сообщения в WhatsApp и заголовок вкладки;
- русский вариант остаётся в `index.html` — если JavaScript отключён,
  сайт показывается на русском.

Все переводы лежат в `i18n.js` в объекте `DICT`: три блока — `ru`, `kk`, `en`.
Ключ (например, `hero.lead`) совпадает с атрибутом `data-i18n` в разметке.
Чтобы поправить текст, найдите ключ в нужном языке и измените строку.

Что можно править в `i18n.js`:

- `meta.title`, `meta.desc` — заголовок и описание страницы;
- `nav.*`, `hero.*`, `catalog.*`, `order.*`, `credit.*`, `tradein.*`,
  `sell.*`, `about.*`, `faq.*`, `contacts.*`, `lead.*`, `footer.*` — блоки страницы;
- `val.*` — названия КПП, кузова и привода в карточках. Ключ — это значение
  из `CARS`, например `"val.Механика"`. Поэтому сами данные авто в `script.js`
  всегда пишутся по-русски, а на сайте показываются на выбранном языке;
- `msg.*` — тексты сообщений, которые уходят в WhatsApp;
- `err.*` — подсказки при заполнении форм.

Новые языки не нужны — но если понадобится четвёртый, добавьте блок в `DICT`
и ещё одну кнопку `data-lang`.

## Как менять автомобили

Все машины лежат в `script.js` в массиве `CARS` в самом начале файла.
Одна карточка = один объект:

```js
{
  brand: "Nissan", model: "Primera P11", year: 1998,
  price: 2000000, mileage: 380255,
  engine: "1.6 л · бензин", transmission: "Механика",
  body: "Седан", drive: "Передний",
  status: "stock", img: "img/car-1.jpg"
}
```

- `status: "stock"` — в наличии, `"order"` — под заказ
- `price` — только число, в тенге (2 000 000)
- `mileage` — только число, в километрах
- `img` — путь к фото в папке `img/`
- `color` — необязательное поле (например, `color: "Серебристый"`).
  Если его нет, строка «Цвет» в карточке просто не показывается

Чтобы добавить авто: скопируйте блок `{ ... }`, вставьте через запятую
и поменяйте значения. Фото положите в `img/` под новым именем.

Каталог и счётчик на главной (`#heroCount`) считаются автоматически —
после добавления или удаления машины ничего вручную править не нужно.

## Фильтры и сортировка

В каталоге работают:

- **наличие** — все / в наличии / под заказ;
- **КПП** — автомат или механика;
- **цена** — до 2 млн, 2–3 млн, 3–5 млн, от 5 млн ₸;
- **кузов** — седан, кроссовер, хэтчбек, минивэн;
- **привод** — передний, задний, полный;
- **сортировка** — по цене и году.

Счётчик «Найдено: N» и кнопка «Сбросить» появляются автоматически.
Названия в фильтрах должны совпадать с полями `transmission`, `body`
и `drive` в `CARS` — иначе машина не попадёт в выборку.

## Избранное

На каждой карточке и в модальном окне есть сердечко. Выбранные авто
сохраняются в браузере посетителя (`localStorage`, ключ
`kazauto03_favorites`) и не пропадают после перезагрузки.

- кнопка с сердечком в шапке показывает количество и открывает подборку;
- в фильтрах есть отдельный чип «Избранное»;
- избранное хранится только на устройстве посетителя — на сервер
  ничего не отправляется.

## Продать авто

Блок «Продать авто» — форма для тех, кто хочет продать машину:

- марка, модель, год, пробег, двигатель, КПП, привод, кузов, цена, город;
- имя и телефон;
- фото автомобиля (JPG/PNG до 15 МБ) с превью и кнопкой удаления.

При отправке собирается готовое сообщение и открывается WhatsApp.
На телефоне, где браузер поддерживает Web Share API, фото уходит вместе
с текстом (системное окно «Поделиться» → WhatsApp). На компьютере
открывается чат с текстом, а фото можно сохранить кнопкой «Сохранить фото»
и прикрепить вручную.

### Дублировать заявки на почту

1. Зарегистрируйтесь на [formspree.io](https://formspree.io) (бесплатно,
   50 заявок в месяц).
2. Создайте форму и скопируйте ссылку вида `https://formspree.io/f/abcdwxyz`.
3. В `script.js` в начале файла вставьте её:

   ```js
   var LEAD_ENDPOINT = "https://formspree.io/f/abcdwxyz";
   ```

После этого заявки приходят на почту, а если сервис недоступен —
посетителю предлагается отправить её в WhatsApp.

Номер WhatsApp задаётся там же, в `script.js`: `var WA_PHONE = "77775907777";`

## Как опубликовать

Сайт статический — ему не нужны база данных, сборка и ИИ-помощник.
Достаточно загрузить файлы на любой бесплатный хостинг статических сайтов:
`index.html`, `i18n.js`, `style.css`, `script.js` и папку `img/`
(`README.md` можно не загружать).

Если на хостинге при входе открывается ИИ-чат или конструктор — его можно
просто закрыть, на публикацию это не влияет. Ниже — варианты без ИИ.

### Netlify Drop (1 минута, без регистрации)

1. Откройте https://app.netlify.com/drop
2. Перетащите папку `kazauto03` целиком в зону загрузки.
3. Через несколько секунд получите ссылку вида `https://name.netlify.app`.
4. Зарегистрируйтесь (кнопка Claim), чтобы ссылка не удалилась и можно было
   обновлять сайт.

Обновление: заходите в сайт → Deploys → снова перетаскиваете папку.
Адрес остаётся прежним.

### Cloudflare Drop (без аккаунта)

1. Откройте https://www.cloudflare.com/drop/
2. Перетащите папку `kazauto03` или её ZIP-архив.
3. Получите ссылку `https://….workers.dev`.
4. В течение часа нажмите Claim, чтобы закрепить сайт за собой, — иначе
   временная ссылка удалится.

### Cloudflare Pages (с аккаунтом)

1. dashboard.cloudflare.com → Workers & Pages → Create → Pages →
   Upload assets.
2. Перетащите папку `kazauto03`, нажмите Deploy.
3. Сайт: `https://имя.pages.dev`. Обновление — новой загрузкой папки.

### GitHub Pages

1. Создайте репозиторий `kazauto03`.
2. Загрузите `index.html`, `i18n.js`, `style.css`, `script.js` и папку `img/`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Сайт: `https://логин.github.io/kazauto03/`.

### Свой домен

Купите домен и привяжите в Netlify, Cloudflare Pages или GitHub Pages
(раздел Custom domain).

## Как отправить клиенту

1. **Ссылка** — Netlify Drop → ссылка → WhatsApp/Instagram. Лучший вариант.

